Short Reflection Week 7

  1. One important layout issue I focused on was making my coffee shop website easier to use on smaller screens. Images and navigation link needed to fit different screen sizes.
  2. I used CSS properties such as max-width margin, padding, and box-sizing to improve the layout. I also added a media query for mobile devices.
  3. On larger screens, the navigation links appear horizontally. On smaller screens, the navigation link stack vertically, making them easier to access.
  4. Testing at different screen widths helped me understand the importance of responsive design. I learned that text, images, and navigation should remain readable and organized on every device.
  5. My improvement would be to create a mobile-friendly navigation menu and improve the arrangement of images and text. This would make the website easier to navigate and more attractive to customers.
